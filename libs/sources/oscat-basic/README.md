# OSCAT BASIC 3.35

This folder holds **OSCAT BASIC 3.35** (`oscat_basic_335.library`), the open-source automation library from
**OSCAT, [www.oscat.de](http://www.oscat.de)** (now hosted by the Eclipse Foundation at
[eclipse.dev/oscat](https://eclipse.dev/oscat)). The file is unmodified (sha256
`0307e2fd307faf6253eae07a146dc9a5f6976ff7c5fa10e8032ba358019882d0`, identical to release 3.35 in [eclipse-oscat/oscat-libs-archive](https://github.com/eclipse-oscat/oscat-libs-archive)).
